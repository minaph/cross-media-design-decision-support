# Resource Registry

This registry records first routes rather than universal winners. Re-check
current URLs, versions, licenses, and usage conditions when they materially
affect a deliverable. Select a resource because it governs a concrete problem,
not as a default visual identity.

## General web and public-service structure

**DADS — Digital Agency Design System**
https://design.digital.go.jp/dads/

Use for Japanese-language web and service-design guidance, accessibility, Figma,
code, tokens, documentation, and related assets.

**GOV.UK Design System**
https://design-system.service.gov.uk/

Use for evidence-driven public-service content, layout, accessibility, and
implementation examples.

**U.S. Web Design System (USWDS)**
https://designsystem.digital.gov/

Use for public-service web patterns, tokens, code, and design kits.

## Product UI and tokens

**Material 3**
https://m3.material.io/

Use for broad application UI, component, token, and interaction guidance.

**IBM Carbon**
https://carbondesignsystem.com/

Use for enterprise and data-rich product interfaces.

**Microsoft Fluent 2**
https://fluent2.microsoft.design/

Use for Microsoft-oriented and cross-platform product UI.

**GitHub Primer**
https://primer.style/

Use for developer-oriented product UI, primitives, accessibility, and Octicons
integration.

## General-purpose icons

**Material Symbols**
https://developers.google.com/fonts/docs/material_symbols

Broad semantic icon vocabulary. Confirm current license and distribution terms
at use time.

**Fluent System Icons**
https://github.com/microsoft/fluentui-system-icons

Coherent interface icon family with SVG and platform packages. Confirm the
current repository license at use time.

**Primer Octicons**
https://primer.style/octicons/

SVG-first icons suited to developer and tooling concepts. Confirm current
license at use time.

## Japanese explanatory illustrations

**Digital Agency illustrations and icons**
https://www.digital.go.jp/policies/servicedesign/designsystem/Illustration_Icons

Use when the visual language and terms fit Japanese administrative or
explanatory communication. Check current print, color, and usage notes before
reuse.

## Print and HTML-to-print

**W3C CSS Paged Media**
https://www.w3.org/TR/css-page-3/

Use for page dimensions, orientation, and paged-media behavior in CSS.

**W3C CSS Color Adjustment**
https://www.w3.org/TR/css-color-adjust-1/

Use for the semantics and limits of print color adjustment.

## Accessibility

**WCAG 2.2**
https://www.w3.org/TR/WCAG22/

Use as the web-accessibility baseline when web accessibility applies.

## Academic posters

**PLOS — Ten Simple Rules for a Good Poster Presentation**
https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.0030102

Use for poster communication goals, rapid recognition, title and claim framing,
and content prioritization. It is not a CSS or print-production specification.

## Cross-media identity and brand operations

**Apple App Store Marketing Resources**
https://developer.apple.com/app-store/marketing/guidelines/

Use as a reference for coordinating digital and print asset rules. Apple assets
remain governed by current proprietary terms.

**Digital Agency logotype kit**
https://www.digital.go.jp/applications/logotype

Use as an example of parallel screen and print sizing and asset variants. Follow
current usage conditions for actual marks.

**Digital Marketplace Visual Identity**
https://www.digital.go.jp/policies/dmp

Use as an example of cross-media visual-identity governance.
