# 改訂スキルの検証記録

対象: 2026-09-28の形成的支援・レビュー支援の分離。対象成果物は `SKILL.md`、5つのreference、設計判断、recap、導入文書である。

## 検証方針

今回の変更は、判断の仕方と参照経路を整理するものである。構造の検査に加え、異なる媒体と正当な反例を含むシナリオで手順を確認する。数値ベンチマーク、複数モデルの比較、反復実行による性能評価、全媒体の実制作は行わない。ポスターの制作例と手順の机上検討を区別する。

## 親の点検と差し戻し

| 対象 | 観察 | 対応 |
| --- | --- | --- |
| 初稿のアンチパターン表 | 元資料のAP番号が独自の別原則へ再割り当てされ、出典とDESIGN・recapの対応が崩れる | 同じ実装担当へ、AP-01〜16の意味対応を保ち、独自原則は別節にするよう差し戻した |
| 対応修正後のAP12 | 操作ターゲットの大きさを、対象読者の設定と取り違えていた | 操作領域・入力方式・間隔を扱う行へ再差し戻し。番号の存在確認と意味の照合を区別した |
| 選択して読む構成 | AP参照が任意すぎると、初回の構成・レビューで診断観点を見落としうる | 関連する失敗機序を一度点検する契機を明記するよう依頼した |
| 有限面の検証 | ポスターv4初稿で、min-heightによりDOMが伸びて二頁になる実例が生じた | DOM内の収まりと、固定された物理ページ内の収まりを分けて検証する指示を追加依頼した |

## 構造・形式

`skill-creator` の `scripts/quick_validate.py` は一時的なuv環境にPyYAMLを用意して実行し、frontmatterは正常だった。プロジェクトの依存関係には追加していない。形式検査だけで手順の意味上の正しさが確認できるとは扱わず、Markdownのローカルリンク、AP番号の意味対応、媒体ごとの判断を別に確認する。

## シナリオの受入観点

次の入力を使い、独立Reviewerに実際の参照経路と判断を確認する。ここでの期待は正解文章の丸暗記ではなく、誤適用と重要な判断の欠落を見つけるための観点である。

| 入力 | 期待する参照と判断 |
| --- | --- |
| A1研究ポスターに余白があり、理論・手順・統計の追加候補がある。データは222件版と232行版が混在 | 形成を選び、候補の価値・根拠・負担を比較。分母・単位・版を確認し、主題に寄与する内容を採用。余白維持も比較対象に含める |
| 独立した商品8点を同じカードで比較するUIのスクリーンショットをレビューしたい | カード数だけで欠陥にしない。比較という正当な役割を評価。画面画像から操作やフォーカスの成功を推定しない |
| 詳細な研究ポスターを5分の口頭発表スライドにしたい。暫定解釈を含む | 形成と媒体routingを選び、提示順・密度を作り直す。ポスターを縮小するだけで済ませず、研究の留保を保持する |
| 20秒動画の絵コンテをレビューしたい。字幕・音声・動きがあるが動画は未出力 | 時間媒体のレビューとして読み順や意図を検討し、字幕の実時間可読性や音声との同期は未検証とする。WebのDOM検査を課さない |
| 静的パンフレットに出典のない数値があり、派生HTMLには表とリンクがある | AP-07は静的資料にも適用。HTMLの意味構造と操作を別途確認。フォームがなければフォーム検査は対象外 |
| 方針だけ決めたい。制作ツールもサブエージェントも利用できない | 計画の範囲で内容・媒体・引き継ぎ・検証計画を完成し、未制作を明記。特定エージェントや新しい承認手順を必須にしない |

## 実成果物での適用

ポスターでは、余白に対して理論・手続き・横断集計を比較し、主題に関わるものを採用した。集計は元TSVから222件、C1 19件、A-4のC1 5件を再現した。初稿は二頁になったため、全体配置を実装担当へ差し戻した。画面とPDFの最終検証およびレビューは、ポスター側の `presentation/qualitative-psychology-poster/validation-notes.md` に詳細を保存する。

## 未検証範囲

今回のシナリオは、スキルの手順を用いた定性的な机上検討である。他媒体での制作効果やユーザー理解の改善を実証する検査ではない。参照する外部資源のURL・版・ライセンスをすべて再調査したものでもない。必要時に現行の公式資料を確認する方針を維持する。
